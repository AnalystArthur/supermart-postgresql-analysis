#SuperMart PostgreSQL Analysis Project

## Overview

This project demonstrates SQL analysis skills using a retail sales dataset containing customers, employees, products, orders, and order items.

The project was completed using PostgreSQL and covers a wide range of SQL concepts used in business reporting and data analysis.

## Dataset

* 800 Customers
* 35 Employees
* 68 Products
* 2,000 Orders
* 5,508 Order Items
* Analysis Period: January 2021 – June 2024

## SQL Topics Covered

## Analysis Performed
